Wire Sniper → Combo (important)
-------------------------------
In Combo Engine inputs → group "CVD Confirm":

  Confirm Mode tip:
    Golden     → pick plot "GoldenBuySrc" / "GoldenSellSrc"
    Any System → pick plot "AnyBuySrc" / "AnySellSrc"
    Any Setup  → pick plot "SniperBuySrc" / "SniperSellSrc"

  Sniper BUY source  → Sniper_CVD_v59 : GoldenBuySrc  (or Any/Sniper)
  Sniper SELL source → Sniper_CVD_v59 : GoldenSellSrc (or Any/Sniper)

If sources stay on `close`, CVD filter will almost never confirm (close is never a pulse).
Start with Require Sniper CVD = OFF to verify mitigation fires, then turn ON after wiring.
