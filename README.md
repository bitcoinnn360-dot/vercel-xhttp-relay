# داشبورد گزارش روزانه بازار — توسعه معادن و فلزات

داشبورد مدیریتی RTL برای گزارش روزانه بازار شرکت سرمایه‌گذاری توسعه معادن و فلزات.
بخش‌های بورس، NAV پرتفو، کامودیتی، زنجیره فولاد چین/ایران و تغییرات دوره‌ای را از روی گزارش اکسل روزانه بازتاب می‌دهد و کامودیتی‌ها را از **TGJU** به‌صورت خودکار تازه می‌کند.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:5173` را باز کنید.

```bash
npm run build   # خروجی production در dist/
npm run preview
```

## منابع داده

| منبع | وضعیت | توضیح |
|------|--------|--------|
| **TGJU** | زنده | طلا، دلار، سکه، مس، آلومینیوم، روی، نفت، بیت‌کوین، گاز |
| **TSETMC** | نمونه / مسدود | شاخص و معاملات — معمولاً نیاز به IP/دسترسی سازمانی |
| **Trading Economics** | نمونه | شاخص‌های جهانی — API پولی یا scrape |
| **Custeel** | نمونه | زنجیره فولاد چین — اشتراک |
| **بورس کالا (IME)** | نمونه از گزارش | ضرایب زنجیره فولاد ایران |

داده‌های seed از گزارش روزانه `1405/04/29` گرفته شده‌اند. هر ۵ دقیقه داشبورد از TGJU تازه‌سازی می‌شود؛ دکمه «تازه‌سازی» هم دستی کار می‌کند.

## ساختار

```
src/
  components/   # بخش‌های داشبورد
  data/         # types، seed گزارش، fetcherهای TGJU
  hooks/        # useMarketData + auto-refresh
  lib/          # فرمت اعداد فارسی
```

## اتصال بعدی به TSETMC / Custeel

وقتی دسترسی سازمانی آماده شد، کافی است adapterهای جدید در `src/data/fetchers.ts` اضافه شوند و فیلدهای `overview` / `stocks` / `steel` را مثل merge فعلی TGJU به‌روز کنند. وضعیت هر منبع در نوار بالای داشبورد نمایش داده می‌شود.
